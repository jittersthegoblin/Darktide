How to use this guide

Follow the named spine

The talent guide tells you the named Blitz, Aura, Ability, modifiers, Keystone and important passive talents to take. Spend the necessary connector/stat nodes between them as you move through the in-game tree.

Flex points are intentional

Weapons change what a build needs. A slow heavy weapon may want different stamina or attack-speed support than a knife or gun, so spare connector points are left flexible instead of pretending one exact point is correct for every loadout.

Patch-sensitive

Darktide balance changes. This version is curated for September 2026 and each talent route links to a current class build database so major tree changes can be checked.
