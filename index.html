How to use this guide

Core route, not a prison

The recommended Blitz, Ability, Aura and Keystone are the spine of the build. Passive nodes are priorities, not commandments. Move flex points if another node makes the build more comfortable for you.

Comfort beats paper DPS

A technically stronger talent is not stronger for you if it makes you die more often. Defensive, cooldown and toughness picks are deliberately valued when you select Tanky, Support or Beginner Friendly.

Patch-sensitive

Darktide balance changes. This version is curated for September 2026. Links in each recommendation lead to current class databases or official class information for extra checking.
