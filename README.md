# Reject Build Cogitator — Darktide

Interactive Warhammer 40,000: Darktide class/playstyle talent recommender.

## Features
- All seven current classes: Veteran, Zealot, Psyker, Ogryn, Arbites, Hive Scum and Skitarii
- Multi-select playstyle tags (melee, ranged, DPS, tank, support, crowd control, horde clear, elite killer, boss damage, mobility, beginner-friendly and high-risk/high-reward)
- Scored build-archetype recommendations
- Core talent-route guidance plus passive priorities
- Runner-up build suggestion
- Copyable build summary
- Responsive grimdark UI

## GitHub Pages
In the repository, open **Settings → Pages** and set **Build and deployment** to **Deploy from a branch**, then choose **main** and **/(root)**.

Once Pages is enabled, the site should be available at:

`https://jittersthegoblin.github.io/Darktide/`

## Note
This is an unofficial fan-made guide. Darktide balance changes over time, so recommendations should be revisited after major class/talent patches.
